# Documentation

This folder contains supporting documentation for teaching, reuse, development, data provenance, and scientific background.

- [Instructor Guide](INSTRUCTOR_GUIDE.md) - teaching design, project scope, support model, assessment, and reuse guidance.
- [Suggested Grading Scheme](GRADING_SCHEME.md) - a suggested assessment scheme for lecturers reusing the course. **Not a course rule** - for students, the course's own published page is what counts.
- [Data Availability](DATA_AVAILABILITY.md) - public data provenance, provider terms, and raw-versus-derived artifact notes.
- [References](REFERENCES.md) - scientific and technical background references.
- [Development Guide](DEVELOPMENT.md) - developer setup, contribution workflow, and maintenance notes.

The root [README](../README.md) remains the student entry point.
