# Frozen contracts

**Committed on purpose.** Everything in this directory is a **frozen contract or a generated artifact that
tooling, tests or CI are held to**. It must survive a fresh clone, because the JupyterHub, the test suite
and anyone reproducing a gate all need to see the contract they are being judged against.

This is the deliberate other half of `DESIGN_DOCS/`, which is **gitignored** (`.gitignore:183`) and holds
working design documents — visions, milestone plans, review logs, codex transcripts. Those are arguments in
progress and stay local. A document moves **here** when it stops being an argument and becomes a rule.

## Rules

1. **A signed contract changes only through its own amendment path** — for the T0 documents that means a
   failure edge back to T0, never an in-flight edit.
2. **Generated artifacts are never hand-edited.** Re-run the generator.
3. **If it is still being argued about, it belongs in `DESIGN_DOCS/`, not here.**
